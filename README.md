# Shruthi Matrimony / Become Worth

Independent creative story and proposed 90-day programme. Static HTML, CSS and JavaScript with Netlify Forms. All illustrations are generated artwork; the project is not affiliated with Shruti Haasan.

Deploy `public` from `main` with no build command. Netlify must have form detection enabled. The `become-worth` form receives name, email, optional phone, focus and intention. No signup details are committed to this repository.

Domain: shruthimatrimony.com. Keep the hosting account on its existing free tier with overage billing disabled.

The twelve scenes use native document scrolling. The lineage section is sticky for a short, scroll-linked reveal; it has no nested scrolling or wheel interception. Reduced-motion users see the complete artwork without the pinned reveal. The only story CTA links to the inline interest form.

Scenes reveal on viewport entry with staggered typography and scroll-linked artwork drift. Scene counters and repeated chapter footers are removed. Reduced-motion preferences disable these effects. The `/for-shruti` open letter includes an independent `creative-conversation` Netlify form for representatives and collaboration enquiries; it does not announce an endorsement, casting, or partnership.

The cinematic story now uses one sticky stage driven by native document scroll, with overlapping dissolves and camera motion for every scene. There are no hidden section runways or wheel/touch interception. The lineage gets a longer tracing/reveal sequence. Reduced-motion mode uses ordinary readable sections; forms remain outside the stage. Project and owner profile URLs are linked in the creator scene and the Foundation experiment credit.

Living pencil effects use one bounded WebGL renderer with reduced-motion, pause, visibility suspension and static fallbacks. Keep the still HTML synchronized with `node scripts/render-story.mjs` after story changes. SEO/AEO checks and remaining opportunities are documented in `docs/seo-aeo-audit.md`.
